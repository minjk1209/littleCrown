# Little Crown

브라우저에서 돌아가는 룰렛 게임. 서버 없이 HTML 파일 하나로 동작하고, 홈 화면에 설치하면 **비행기모드에서도** 실행됩니다.

**🔗 https://minjk1209.github.io/littleCrown/**

---

## ⚠️ 코드를 고쳤다면 반드시 할 것

**`sw.js` 의 캐시 번호를 올리세요.** 안 올리면 폰에 변경이 반영되지 않습니다.

```js
// sw.js
const CACHE = 'littlecrown-v40';   // ← 숫자를 올린다
```
```js
// littleCrown.html 끝부분
const APP_VERSION = 'v40';         // ← 같이 올린다 (화면 왼쪽 아래에 표시됨)
```

서비스 워커가 파일을 캐시해두기 때문에, 번호가 그대로면 폰은 **옛 버전을 계속 보여줍니다.**
화면 왼쪽 아래 작은 뱃지로 지금 떠 있는 버전을 확인할 수 있습니다.

반영 순서:
1. `git push` → GitHub Pages 가 1~2분 뒤 배포
2. PC: `Ctrl+Shift+R` 두 번 / 폰: 앱 **두 번** 열기
   (캐시 우선 방식이라 첫 번째에 새 버전을 받고 두 번째에 적용됩니다)

## 파일 구성

```
littleCrown.html   게임 전체 (HTML + CSS + JS 한 파일)
index.html         루트 접속 시 게임으로 보내는 리다이렉트
manifest.json      PWA 설정 (앱 이름, 아이콘, 전체화면)
sw.js              서비스 워커 — 오프라인 실행을 담당
icons/             홈 화면 아이콘 4종
```

외부 라이브러리·CDN·서버를 **하나도 쓰지 않습니다.** 모든 경로가 `./` 상대 경로라
어느 호스팅의 어느 하위 폴더에 올려도 수정 없이 동작합니다.

로컬에서 보려면 파일을 그냥 브라우저로 열면 됩니다. 다만 `file://` 에서는 서비스 워커가
등록되지 않아 PWA 기능은 확인할 수 없습니다. 그때는:

```bash
python -m http.server 8000      # http://localhost:8000/littleCrown.html
```

`localhost` 는 보안 컨텍스트로 취급되어 서비스 워커가 정상 동작합니다.

## 데이터

서버가 없으므로 **모든 데이터는 브라우저의 localStorage 에만** 저장됩니다.

| 키 | 내용 |
|---|---|
| `casino_vip_balance_uni` | 지갑 잔액 |
| `casino_vip_vault_uni` | 금고 잔액 |
| `casino_vip_hist_eu` / `_am` | 테이블별 스핀 기록 (최근 300개) |
| `casino_vip_freq_eu` / `_am` | 테이블별 숫자 출현 횟수 |
| `casino_vip_inventory` | 보유 아이템 |
| `casino_vip_equipped` | 장착 중인 스킨 |
| `casino_vip_img_eu` / `_am` | 딜러 사진 (256px JPEG, base64) |
| `casino_vip_used_vouchers` | 사용한 수표 목록 |
| `casino_vip_recharge_day` | 마지막 충전 날짜 |

### 주소가 바뀌면 데이터가 날아갑니다

브라우저는 주소가 다르면 완전히 다른 사이트로 봅니다. 저장소 이름 변경, 도메인 연결,
다른 호스팅으로 이전 — 전부 해당됩니다.

```
① 지금 주소에서  금고 → 💾 백업   (JSON 파일로 저장)
② 주소 변경
③ 새 주소에서   금고 → 📂 복원
④ 폰: 옛 홈 화면 아이콘 삭제 → 새 주소로 다시 추가
```

백업/복원은 위 12개 키를 전부 담습니다. 기기 간 데이터 이사에도 같은 방법을 씁니다.

## 자주 건드리는 값

전부 `littleCrown.html` 안에 있습니다.

| 상수 | 기본값 | 설명 |
|---|---|---|
| `RECHARGE_AMOUNT` | `9000` | 충전 버튼 한 번에 들어오는 금액 |
| `RECHARGE_DAILY_LIMIT` | `true` | `false` 로 바꾸면 하루 1회 제한이 풀립니다 (테스트용) |
| `EDGE_RATIO` | `0.36` | 칸 가장자리 판정 폭. 분할·코너 베팅 영역의 크기 |
| `ZERO_EDGE_RATIO` | `0.18` | 1번 열 왼쪽의 **0 조합** 베팅 영역. 좁힐수록 1·2·3 이 잘 잡힙니다 |
| `DRAG_SLOP` | `6` | 이 픽셀 이상 움직여야 칩 '옮기기'로 봅니다. 그 미만은 '같은 자리에 추가' |
| `HISTORY_MAX` | `300` | 테이블당 보관할 스핀 기록 개수 |
| `RT_NEIGHBOURS` | `2` | 레이스트랙 이웃 베팅에서 양옆 몇 칸까지 묶을지 |
| `RT_RO / RT_L / RT_TN / RT_TS` | `200 / 600 / 62 / 60` | 레이스트랙 타원의 반지름 / 직선부 길이 / 숫자띠 / 구역띠 두께 |
| `DEALER_IMG_SIZE` | `256` | 딜러 사진을 줄여서 저장할 크기 |

### 베팅 판정 구조

칸의 **어디를** 누르느냐로 베팅 종류가 정해집니다. 판정 폭은 칸 크기에 비례합니다
(`EDGE_RATIO`). 화면이 좁아져 칸이 작아져도 비율이 유지되도록 한 것이고,
고정 픽셀을 쓰면 작은 화면에서 위·아래 영역이 겹쳐 **단일 숫자 베팅이 불가능해집니다.**

1번 열(숫자 1·2·3)의 왼쪽만 `ZERO_EDGE_RATIO` 로 더 좁게 봅니다.
여기는 0 과 묶이는 구역이라, 다른 가장자리와 같은 폭을 쓰면 1 이나 2 를 평범하게 눌러도
0 이 끼어들기 때문입니다.

### 배당 계산은 한 곳에만

`computeWinnings(bets, winNum)` 하나입니다. 보고 있는 테이블과 뒤에서 도는 테이블이
같은 함수를 씁니다. **배당 식을 다른 곳에 또 적지 마세요.** 두 경로가 갈라지면 반드시 어긋납니다.
화면에 표시하는 배당(`describeBet`)도 같은 식(`36 / 숫자개수`, 파이브 넘버만 7)을 씁니다.

## 주요 기능

- **두 테이블 동시 진행** — 유럽/아메리칸이 15초 어긋나게 돌아갑니다. 보고 있지 않은
  테이블도 자체 타이머로 정산되고, 결과는 상단 알림과 우측 상단 미니 휠로 보여줍니다
- **레이스트랙** (유럽 전용) — 휠 순서대로 배치된 타원형 입력판. 콜 벳 4종
  (Voisins / Tiers / Orphelins / Jeu Zéro)과 이웃 베팅. 아메리칸은 휠 순서가 다르고
  00 이 있어 정식 구역이 정의되지 않으므로 탭이 비활성화됩니다
- **수표** — 지갑에서 금액을 빼 코드로 만듭니다. 발행 즉시 차감되고 입금 시 가산됩니다.
  기기 간에 금액 일부만 옮길 때 씁니다
- **백업 / 복원** — 공유 시트 → 파일 다운로드 → 클립보드 순으로 시도합니다

## 아직 확인하지 못한 것 (iOS)

iPhone / iPad 에서 **실제로 돌려본 적이 없습니다.** 기기가 생기면 아래를 확인하세요.

| 확인할 것 | 문제 시 대응 |
|---|---|
| **레이스트랙 숫자가 칸 세로 중앙에 있는지** | Safari 가 `dominant-baseline` 을 제대로 처리하지 못하면 어긋납니다. 그 속성 대신 `y` 좌표를 직접 계산하면 해결됩니다 |
| 수표 발행 시 코드가 복사되는지 | iOS 는 사용자 제스처 조건이 엄격합니다. 실패하면 입력칸에 코드가 뜨는 폴백이 동작합니다 (정상) |
| 백업 시 공유 시트가 뜨는지 | 실패하면 다운로드 → 클립보드로 폴백합니다 |
| 하단 버전 뱃지가 홈 인디케이터와 겹치는지 | `.ver-badge` 의 `bottom` 값을 올리면 됩니다 |
| Safari 에서 홈 화면 추가 → 비행기모드 실행 | — |

### iOS 고유 제약 (코드로 해결 불가)

- 홈 화면 웹앱을 **몇 주 안 열면 저장 데이터가 정리될 수 있습니다.** `navigator.storage.persist()`
  를 호출하지만 iOS 에서는 효과가 제한적입니다. **정기적인 백업이 유일한 보험입니다**
- Safari 와 설치한 앱의 저장소가 분리될 수 있습니다. 한 쪽에서만 쓰는 게 안전합니다
- 앱을 백그라운드로 내리면 타이머가 멈췄다가 돌아올 때 이어집니다 (흐른 시간을 따라잡지 않음)

## 알려진 한계

- **수표는 복제 가능합니다.** "사용한 수표" 목록이 기기마다 따로 저장되므로, 같은 코드를
  다른 기기에서 또 쓸 수 있습니다. 막으려면 서버가 필요합니다
- **저장 데이터는 수정 가능합니다.** 개발자도구나 백업 파일을 열어 잔액을 바꿀 수 있습니다.
  혼자 하는 게임이라 그대로 두었습니다
- **기기마다 데이터가 따로입니다.** 공유하려면 백업/복원이나 수표를 쓰세요
- **폰의 강제 다크 모드**를 켜면 레이스트랙 색이 연해 보입니다. 브라우저가 SVG 를 다시
  칠하기 때문이고 코드로 막을 수 없습니다 (`color-scheme: dark` 로 Chrome 은 막히지만
  삼성 인터넷은 무시합니다). 브라우저 설정에서 "웹페이지도 어둡게" 를 끄세요
